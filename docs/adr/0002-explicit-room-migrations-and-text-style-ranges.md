# Room 演进使用显式迁移，日记样式按文本范围持久化

首轮真机反馈要求同一日记文本块内的任意选区可以拥有不同颜色和字号，而旧模型只有整行颜色。继续沿用整行字段会丢失用户选择，改成完整富文本引擎又会引入不必要的编辑器复杂度；因此保留有序 Journal Block，并在文本块内保存经过规范化的非重叠样式范围。样式范围支持有限颜色、字号、粗体、斜体、下划线、删除线和荧光笔；段落级只保留当前文本块在正文宽度内的左、中、右对齐，不扩展成项目符号、编号或勾选清单。v9 曾短暂持久化的清单状态由显式 v9→v10 数据迁移恢复为普通文本，正文和其他富文本样式不变。所有已安装数据库从 v1 起使用显式 Room Migration 和迁移回放测试，禁止 destructive fallback。
