# 咸鱼大王

咸鱼大王是一款本地优先的 Android 个人生活记录应用，包含日期待办、习惯打卡、多媒体日记和人生清单。

## 当前功能

- 当日和连续周待办，支持提醒、截止范围、TAG 和拖动排序。
- 每日、每周或每月习惯，支持指定日期或只设置周期内次数。
- 同日多条日记时间线，支持图片、动图、视频、录音、地点、TAG 和内容关联。
- 人生清单和人生轨迹，可与待办及日记关联。
- 加密本地备份/恢复，并可通过 GitHub Releases 检查更新。

## 构建

需要 JDK 17 和 Android SDK 35。

```powershell
.\gradlew.bat :app:assembleDebug
```

APK 会生成在 `app/build/outputs/apk/debug/`。

## 数据与隐私

业务数据默认保存在设备本地的 Room 数据库中，日记媒体复制到应用私有目录。备份文件由用户密码加密；应用不会将 GitHub Token 写入 APK。
